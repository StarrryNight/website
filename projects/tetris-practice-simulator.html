Tetris Practice Simulator

A Unity Tetris game with custom scenarios for practicing advanced techniques

Visit project

I was in a Tetris club and we all had the same problem: you can only practise a T-spin when the board happens to give you one, which is almost never when you want it.

So I built a Unity Tetris where you set the board up yourself. You place the pieces where you want them, save that position, and drill it. T-spins, combos, whatever technique you are trying to get automatic.

The club used it for training.
